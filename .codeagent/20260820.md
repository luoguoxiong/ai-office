# 2026-08-20 任务日志

## 修复:打包版预览 Office 提示「需要安装 officecli」

**现象**:`pnpm tauri:build` 打包的 AI Office.app 中打开 Office 文件提示「预览 Office 文档需要安装 officecli:npm i -g @officecli/officecli 或 brew install officecli」。

**根因**:`src/tools/officecli.ts` 的 `resolveOfficeCliBin()` 用 `require.resolve('@officecli/officecli/package.json')` 定位本地二进制。但 `@officecli/officecli` 的 package.json 中 `exports` 只暴露 `"."`,解析 `./package.json` 抛 `ERR_PACKAGE_PATH_NOT_EXPORTED`,函数静默回退到 PATH 中的 `officecli`。dev 模式下 pnpm 会把 `node_modules/.bin` 加入 PATH 所以正常;打包后 App 的 PATH 不含 `.bin`,导致检测失败。

**修复**:改为 `require.resolve('@officecli/officecli')` 解析包入口(`lib/install-binary.js`),再向上取包目录拼接 `vendor/officecli`,并用 `package.json + vendor 二进制存在`双重校验;最后仍回退 PATH。dev 与打包布局均生效。

**验证**:
- 用打包内 runtime node 跑 `dist/server.js`,启动 banner 显示 `officecli: ✅ 已安装`(修复前 ❌)
- `/api/v1/file/open` 返回 `kind:'office'` + previewUrl(修复前返回 officecli 错误提示)
- `pnpm typecheck` 通过

**后续**:需重新执行 `pnpm tauri:build` 使 .app 包含修复后的代码。

**打包结果**:已重新执行 `pnpm tauri:build`(20:49 完成):
- ✅ `src-tauri/target/release/bundle/macos/AI Office.app` 构建成功,内含修复后的 `dist/tools/officecli.js` + `vendor/officecli` 二进制 + runtime/node
- ❌ DMG 制作失败:trae 沙箱禁止访问 `/dev/rdisk*` 设备(bundle_dmg.sh 需要挂载磁盘镜像)。如需 DMG,请在沙箱外自行运行 `pnpm tauri:build`;仅用 .app 则直接拖入 /Applications 即可。
